This project's aim is to create a multi-task classifier model that can determine whether a given sentence contains logical fallacies, or hate speech or not. The model uses one shared encoder with three task-specific heads to handle fallacies, hate speech and rationale. As for the results, the overall weighted F1 is measured to be 0.805 with F1 for fallacy classification being 0.83, hate speech detection 0.77 and rationale identificaiton 0.78.
